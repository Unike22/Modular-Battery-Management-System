# Modular Battery Management System (BMS)

## Project Overview
This project implements a Modular Battery Management System (BMS) using ESP32 on the Wokwi simulation platform. The system monitors multiple battery cells, identifies the strongest and weakest cells, calculates voltage imbalance, estimates the State of Charge (SoC), and generates adaptive imbalance warnings.

## Features
- Modular and scalable architecture
- Battery cell voltage monitoring
- Strongest and weakest cell detection
- Voltage imbalance calculation
- State of Charge (SoC) estimation
- Adaptive imbalance threshold
- Imbalance trend monitoring
- Serial Monitor output

## Hardware
- ESP32
- 4 Potentiometers (Battery Cell Simulation)
